# noctalia-kitty-control

Noctalia bar and panel plugin (`community/kitty-control`) for configuring Kitty terminal appearance, typography, opacity, and themes.

## Usage

- **Noctalia plugin source**: add this repository as a Noctalia plugin source (`catalog.toml` + `kitty-control/`).
- **Nix flake**: provides `packages.x86_64-linux.plugin` (default), `lib.pluginDir`, and `checks.x86_64-linux.manifest`.
